## 🔧 개선 방안

### 즉시 적용 (완료)

| 문제 | 개선 조치 |
|------|-----------|
| 병합 안내 불명확 | "병합하려면: 병합해"라고 명확히 안내 |
| Copilot 누락 | 재리뷰 요청 체크리스트에 Copilot 추가 |
| 한글 작성 | 스킬 핵심 원칙 #1에 "모든 댓글은 한글로" 추가 |

### PR 리뷰 사이클 프로세스 개선

```
PR 상태 확인 순서 (개정):
1. 미해결 코멘트 수 확인 (in_reply_to_id 기준) ← 먼저!
2. CI 상태 확인
3. 두 리뷰어 모두에게 재리뷰 요청 ← 필수!
4. 3분 폴링 시작
5. 재리뷰 결과 확인 후 병합 가능 여부 판단
6. 병합은 사용자 승인 후에만
```

### 향후 적용

1. **서브에이전트 태스크에 모든 지시사항 직접 명시**
   - 스킬에 있어도 서브에이전트는 안 읽음
   - "한글로 작성", "검증 결과 댓글 등록" 등 명시 필요

2. **재리뷰 결과 반드시 확인**
   - 서브에이전트 완료 후 메인 에이전트가 검증
   - "재리뷰 완료"라고 보고해도 직접 확인

3. **자동 병합 절대 금지**
   - 사용자가 "병합해" 또는 "/merge"라고 명시할 때만
