- **원인**: PR 리뷰 답글 프로세스가 명시되어 있지 않음

### 해결 방법
```bash
# 인라인 리뷰 코멘트에 답글
gh api repos/<owner>/<repo>/pulls/comments/<comment-id>/replies \
  --method POST -f body="답글 내용"
```
