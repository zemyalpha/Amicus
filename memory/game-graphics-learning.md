## 🎨 게임 UI 디자인 베스트 프랙티스 (2024-2025)

### 1. 레이아웃 & 사이징
- **Viewport-relative sizing**: `%`, `vw/vh` 단위 사용
- **CSS calc()**: 유연한 레이아웃
- **고정 px 금지**: 다양한 화면 크기 대응

### 2. 그래픽
- **SVG graphics**: 벡터 기반 UI (완벽한 스케일링)
- **3D 카툰 스타일**: 밝고 화려운 색상
- **다층 배경**: 하늘/산/지형/길 레이어
- **그라데이션 & 그림자**: 깊이감 있는 디자인

### 3. 타이포그래피
- **Bold & Capitalized**: 크고 굵은 텍스트
- **명확한 계층**: 제목/부제/본문 구분
- **가독성 우선**: 적절한 줄 간격

### 4. UI 요소
- **HUD (Heads-Up Display)**: 점수/레벨/체력 표시
- **메뉴**: 직관적인 아이콘
- **버튼**: 크고 클릭하기 쉬운 영역
- **피드백**: 애니메이션, 사운드 효과

### 5. 인터랙션
- **터치 지원**: 스와이프, 탭
- **키보드 지원**: WASD, 화살표, 스페이스
- **반응형 디자인**: 모바일/태블릿/데스크톱
